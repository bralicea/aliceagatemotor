# `assets/brand/` — Alicea's Gate Motor Pro logo

Logo concept #1 ("Van Script"), chosen by Bryan on 2026-10-16 from the logo concepts canvas.

| File | Use |
| --- | --- |
| `alicea-logo.svg` | Full color, for light backgrounds: red script, white keyline, ink block shadow, red swoosh, ink GATE MOTOR PRO |
| `alicea-logo-reversed.svg` | For dark backgrounds: red script, white keyline, red swoosh, white GATE MOTOR PRO (no shadow) |
| `alicea-icon.svg` | App icon / favicon: white script A with ink shadow on a red rounded square |

All lettering is converted to outlines, so the files need no fonts and can go straight to print,
vinyl or embroidery vendors. Outlines were shaped with HarfBuzz from Playball 400 (TypeSETit,
SIL OFL 1.1) and Hubot Sans italic at wght 900 / wdth 125 (GitHub, SIL OFL 1.1), the same files
in `assets/van/fonts/`. The OFL permits using a font's outlines in a logo.

Colors: red #C70F10, ink #090E11, white #FFFFFF.
